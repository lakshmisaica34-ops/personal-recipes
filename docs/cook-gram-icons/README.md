# Cook Gram icon concepts

Three original vector directions, drawn as 512×512 SVGs with launcher-scale simplicity in mind:

1. **Recipe card** — a saved recipe with a bookmark; strongest signal for a personal recipe library.
2. **Serving bowl** — warm, food-first, and language-neutral; more like a cooking brand than a recipe organizer.
3. **Saved bite** — a recipe card with a heart and saved check; friendly and social without using an Instagram-like camera mark.

These are concept sketches, not final Android adaptive-icon exports. The chosen direction should be tested at small sizes and then exported as foreground/background assets with Android safe-area padding.
